# 🤖 Что умеет этот AI-агент

Этот файл содержит актуальный список возможностей AI-агента AI_Agent_Artik.

Здесь перечислено только то, что реально присутствует в текущей версии проекта и было проверено — чтением кода, автоматическими тестами (54 теста, все зелёные) и, где это было безопасно, реальным запуском. Ничего из написанного ниже не выдумано.

Один и тот же агент работает тремя способами одновременно: как консольная программа (CLI), как Telegram-бот и как чат в браузере (веб-интерфейс). Разницы в возможностях между ними почти нет — везде одна и та же память, одни и те же инструменты.

---

## 💬 Общение

В обычном разговоре агент отвечает через AI-модель (OpenRouter). Он помнит последние 100 сообщений текущего диалога (краткосрочный контекст) и то, что ты попросил запомнить навсегда (долговременная память, см. ниже).

Примеры:

```text
объясни async/await простыми словами
что такое RAG
расскажи про MCP
```

## 🧠 Память

Агент умеет запоминать факты и напоминания навсегда, отдельно для каждого чата (у тебя в Telegram, у другого человека в другом чате, в браузере — все свои записи).

**Как попросить запомнить:**

```text
запомни я учу JavaScript
запомни мой основной язык программирования JavaScript
/remember
```

(`/remember` без текста сохраняет твоё последнее сообщение.)

**Как посмотреть память:**

```text
память
что ты помнишь
/memory
/history
```

`/history` показывает записи с номерами — это нужно для `/forget`.

**Как найти конкретную запись:**

```text
/memory search JavaScript
```

**Как удалить:**

```text
/forget 2
/forget я учу JavaScript
/clear
```

`/forget` понимает и номер записи, и точный текст. `/clear` стирает всю память текущего чата.

Память хранится в PostgreSQL, если у бота настроена база данных, иначе — в обычном файле `memory.json` рядом с программой. Если база данных временно недоступна при запуске, бот всё равно запускается и работает — просто в этот момент операции с памятью на некоторое время не сработают, а не всё приложение целиком.

## 🤖 Режимы агента

У агента три «личности» — переключаются командой `/agent <режим>` или разовым вопросом через `/coder`/`/architect`.

### 🙂 Обычный (`default`)

Личный ассистент для повседневных вопросов: советы, объяснения, техническая помощь. Настроен отвечать прямо и подробно, не уходя от сложных или спорных тем — это осознанная настройка для личного использования владельцем бота, а не публичный сервис с ограничением тематик.

### 👨‍💻 Программист (`coder`)

Senior JavaScript Developer и AI Engineer — для вопросов про JavaScript, Node.js, Telegram-ботов на Telegraf, AI-агентов. Отвечает готовым кодом, без длинной теории.

```text
/agent coder
объясни Promise.allSettled

/coder напиши функцию проверки email
```

### 🏗 Архитектор (`architect`)

Solution Architect — для проектирования систем: стек, структура проекта, план разработки, потенциальные проблемы.

```text
/agent architect
спроектируй Telegram AI-агента с памятью

/architect как масштабировать бота на 10000 пользователей
```

`/agents` — список режимов. `/agent` — какой режим включён сейчас. `/model` — какая модель используется в текущем режиме.

## 📂 Файлы

Агент умеет работать с файлами внутри своего собственного проекта (не с произвольными файлами компьютера):

```text
прочитай файл src/agent.js
покажи файл README.md
структура проекта
```

`/write путь | текст` создаёт или перезаписывает файл проекта. Все три операции защищены от выхода за пределы каталога проекта и не дают прочитать или перезаписать `.env`-файлы с секретами.

**Анализ кодовой базы** — агент собирает срез своего же проекта (ключевые файлы, `src/`, `test/`, до 8000 символов на файл, до 70000 суммарно) и просит AI-модель провести ревью: архитектура, сильные стороны, проблемы, что исправить первым.

```text
/codebase
проанализируй мой проект
найди ошибки в проекте
```

## 📊 Excel

Самая крупная и тщательно проверенная часть агента — работа с `.xlsx`, `.xls` и `.csv`. Бот сам берёт последний присланный файл или файл, названный в запросе; если один магазин встречается в нескольких выгрузках — берётся самая свежая, чтобы продажи не посчитались дважды.

### 📦 Заказ поставщику

Два независимых способа посчитать, что нужно заказать:

- **По отчёту о движении/продажах** («замовлення Т1») — самый частый сценарий: прислал боту выгрузку 1С/BAS → получил файл с рекомендованным заказом.
- **По остаткам и прайсу поставщика** — если есть отдельные файлы остатков и прайса поставщика.

```text
подготовь заказ поставщику
/excel замовлення data/t1.xlsx
/excel заказ остатки=data/ostatki.xlsx прайс=data/price.xlsx
```

По умолчанию заказ идёт по любому товару. Можно сузить до конкретной категории:

```text
заказ только презервативы и лубриканты
заказ поставщику весь товар
```

Пороги настраиваются прямо в запросе: `продаж%=20`, `days=90`, `периодов=3`, `prefixes=PJ,SO`, `период=30`.

Файл заказа всегда содержит второй лист «Переміщення» — то, что решили не заказывать заново, а перевезти между своими магазинами.

### 🎯 Перенос товара по условию

```text
перенеси где реализация<20%
перенеси с Т1, Т7 и Т9 на Т10 где остаток>3
перенеси с Т1 на Т9 и Т10 кроме Т5 где запас>60
```

Понимает названия магазинов в любом виде («с Т1», «с Toppers 1», «на ХОХО 2»), несколько условий сразу, исключения.

### ♻️ Развезти неликвид по продажам

```text
развези по продажам
перемещение по нулевым продажам
```

Забирает товар со складов, где он не продаётся, и распределяет туда, где продаётся — пропорционально продажам получателей.

### 🔀 Документ перемещения

Разбирает уже готовую книгу с листами-маршрутами (любую из трёх реальных форм именования листов) в одну таблицу:

```text
перемещение
шаблон перемещения с Т10
Т10 на Т1: SO3206 12, PJ10440 2
```

Последний вариант — перемещение прямо текстом, без Excel вообще.

### 🗂 Непроданное

```text
что не продалось
непроданное
неликвид
```

Собирает из нескольких файлов товары, у которых за весь период не было ни розничных, ни оптовых продаж.

### ✂️ Фильтр, поиск, аналитика

```text
оставь только pjur
удали всё кроме презерватив
найди PJ10050 в таблице
аналитика по excel-файлу
```

### 📑 Листы книги

```text
покажи листы
создай лист Т9
удали лист Т5
переименуй лист Т5 в Т9
скопируй лист Т5 в Т9
```

Исходный файл никогда не меняется — бот всегда присылает новую книгу.

### ✏️ Правка ячеек

```text
поменяй артикул A123 на B456 в data/ostatki.xlsx
```

Разбирает запрос через AI-модель в точный план правки, перед каждым изменением делает резервную копию файла в `backups/`.

Полная справка по всем командам Excel-модуля: `/excel` без аргументов.

## 🌐 Интернет

| Инструмент | Что делает | Нужен ключ |
|---|---|---|
| Поиск (`/search`, «найди …») | Ищет через Tavily, отдаёт краткий ответ и источники | `TAVILY_API_KEY` |
| Новости (`/news`) | Последние новости по теме через Google News | нет |
| YouTube (`/youtube`, `/yt`) | До 5 видео по запросу | `YOUTUBE_API_KEY` |
| Погода (`/weather`) | Короткий прогноз через wttr.in | нет |
| Чтение страниц («прочитай сайт …») | Достаёт текст страницы и делает конспект | нет |

```text
/search что такое Model Context Protocol
/news искусственный интеллект
/youtube JavaScript event loop
/weather Киев
прочитай сайт https://nodejs.org
```

В Telegram есть отдельная кнопка «🌐 Веб-поиск» — та же функция, но с индикатором стадий («Ищу...» → «Анализирую...») прямо в чате.

⚠️ Чтение страниц пока не ограничено списком разрешённых адресов — если бот развёрнут в облаке, теоретически можно попросить его обратиться к внутреннему адресу хостинга.

## 🎨 Картинки

```text
/draw кот-программист в космосе
нарисуй дракона в горах
```

Рисует через AI-модель (по умолчанию `google/gemini-2.5-flash-image`) и сохраняет в `exports/`. Уже нарисованную картинку можно поправить:

```text
/editimage добавь снег
измени картинку: сделай фон синим
```

В Telegram можно вместо этого просто ответить (reply) текстом на любое фото в чате, не только нарисованное ботом, — оно отредактируется тем же образом.

## 💻 Веб-интерфейс

Чат в браузере поверх того же агента — без Telegram и без терминала. Поднимается сам вместе с CLI или Telegram-режимом:

```text
http://localhost:10000
```

Умеет: обычный чат с индикатором «печатает», переключение роли кнопками в шапке, кнопки быстрых действий для Excel, загрузку Excel/CSV файла, скачивание готовых отчётов и картинок. У каждой вкладки браузера — своя сессия и своя память на 30 дней.

⚠️ Аутентификации нет — как и у Telegram-бота, любой, кто откроет адрес, может пользоваться агентом.

## 📱 Telegram

```bash
npm run telegram
```

Бот отвечает на текст, голосовые и аудио-сообщения (распознаёт речь через AI), показывает кнопки для смены роли, рисования и веб-поиска, присылает готовые Excel-отчёты и картинки прямо файлами, делит длинные ответы на части. Есть кнопка «🖥 Веб-версия», открывающая тот же чат в браузере.

Можно ограничить круг людей, которым бот отвечает, двумя способами:

- **Список ID** — переменная `ALLOWED_CHAT_IDS` со списком Chat ID через запятую (свой ID показывает `/whoami`).
- **Регистрация по коду** — переменная `REGISTRATION_CODE`. Если она задана, бот закрыт по умолчанию: незнакомый человек получит «Этот бот приватный» на что угодно, кроме `/start`. Доступ открывает `/start <код>` с верным кодом — дальше этот chatId запомнен навсегда.

```text
/start твой-код-регистрации
```

Без обеих переменных бот отвечает всем — как и раньше.

```text
создай проект Telegram Shop Bot

```

Повторное «создай проект X» на уже существующий проект не стирает его данные — покажет текущую карточку.

СПРАВКА: ЧТО ПИСАТЬ TELEGRAM-БОТУ ВРУЧНУЮ
Проверено по коду AI_Agent_Artik и config.yaml: 6 сентября 2026 года.

1. КАК НАЧАТЬ

Отправь боту файл .xlsx, .xls или .csv как документ. Дождись «Файл получил», затем отправь действие отдельным текстовым сообщением. Подпись к файлу сама по себе действие не запускает.

Примеры ниже можно копировать. Для Excel надёжнее писать /excel перед запросом: так он попадёт прямо в обработчик таблиц.

Пути вида data/ostatki.xlsx — примеры. Вместо них вставляй реальный путь из ответа «Файл получил», например data/telegram/123456/1234567890-ostatki.xlsx. Бот работает с файлами внутри своего проекта; путь к произвольному файлу на компьютере не заменяет загрузку в Telegram.

Важно: файлы накапливаются. Некоторые операции используют несколько выгрузок из памяти чата, а не только последнюю. Явно указанный путь тоже не всегда исключает остальные файлы из памяти. Проверяй в ответе бота число файлов и названия источников. При объединении отчётов по точкам предусмотрен отбор самой свежей выгрузки одной точки по времени изменения файла.

3. НАЙТИ ТОВАР И ПОСМОТРЕТЬ АНАЛИТИКУ

/excel поиск PJ10050
/excel поиск шампунь
/excel поиск PJ10050 data/ostatki.xlsx
/excel аналитика
/excel аналитика data/ostatki.xlsx

Поиск ищет строки по значениям колонок и возвращает источник: файл, лист и номер строки. Аналитика даёт сводку по таблицам.
Не пиши просто «найди PJ10050»: без указания Excel такая фраза может запустить интернет-поиск.

4. ЗАКАЗ ПОСТАВЩИКУ

По загруженному отчёту продаж или движения:
/excel замовлення
/excel заказ поставщику
/excel замовлення data/t1.xlsx
/excel заказ поставщику только презервативы и лубриканты
/excel заказ поставщику весь товар

«Замовлення» явно выбирает расчёт по отчёту продаж/движения. «Заказ поставщику» выбирает подходящий сценарий по доступным данным. Не каждая произвольная таблица подходит: нужны распознаваемые колонки отчёта.

Параметры расчёта замовлення — дописываются в то же сообщение:
• продаж%=20 — минимальная реализация 20%; сейчас по умолчанию 40%.
• days=90 — лимит дней запаса; по умолчанию 45.
• target=3 — закупка на три периода продаж; по умолчанию два.
• период=30 — длительность исходного отчёта в днях.
• prefixes=PJ,SO — отобрать только эти префиксы артикулов; пиши параметр последним.

Полный пример:
/excel замовлення продаж%=20 days=90 target=2 период=30 prefixes=PJ,SO

Если пишешь период=30, явно ставь target=2 ПЕРЕД ним: текущий разбор параметров может иначе принять «период=30» также за число периодов закупки. Для длительности отчёта без дат используется настройка 18 дней; для отчёта за два года указывай период=730.

По умолчанию категории не ограничены презервативами и лубрикантами. «Весь товар» снимает ограничение категорий, но остальные условия расчёта продолжают действовать.

Отдельный сценарий по остаткам и прайсу:
/excel заказ остатки=data/ostatki.xlsx прайс=data/price.xlsx

Вместо примерных путей вставь пути к двум загруженным файлам. Параметры замовлення выше относятся к отчёту продаж; не считай их универсальными настройками любого заказа.

5. ПЕРЕНОС МЕЖДУ МАГАЗИНАМИ ПО УСЛОВИЯМ

/excel перенеси где реализация<20%
/excel перенеси с Т1, Т7 и Т9 на Т10 где остаток>3
/excel перенеси с Т1 на Т9 и Т10 кроме Т5 где запас>60
/excel перенеси с Toppers 1 на ХОХО 2 где продаж<3
/excel перенеси с Т1 где остаток>10 реализация<40%
/excel перенеси с Т1 на Т10 где реализация<20% период=730

Условия отбора товара:
• реализация — процент реализации;
• продаж — количество продаж;
• остаток — количество товара;
• запас — дни запаса.

Используй знаки <, >, <=, >=. Несколько условий можно написать рядом. Одиночное «=» не используй как единственное условие переноса: хотя оно упомянуто во встроенной помощи, переключатель этого режима его не распознаёт.

Точки удобнее писать кодами Т1, Т7, Т10, Х2. Получатели должны присутствовать в исходных данных.

Текущие правила переноса из config.yaml:
• получатель продаёт этот товар и имеет менее 30 дней запаса;
• довоз рассчитывается до 36 дней запаса;
• минимальная партия — 2 штуки;
• сертификаты с артикулами вида p500 исключаются;
• то, что не требуется получателям, остаётся на источнике.

Эти настройки читаются из конфигурации; фраза «минимальная партия 1» не является подтверждённой командой изменения настройки.

6. РАЗВЕЗТИ ТОВАР ПО ПРОДАЖАМ

/excel развези по продажам
/excel перемещение по нулевым продажам

Это отдельный сценарий: рассчитать перемещение из точки, где товар не продаётся, в точки, где он продаётся. Нужны отчёты по магазинам. Для собственного порога реализации или остатка используй раздел 5.

7. СОБРАТЬ ДОКУМЕНТ ПЕРЕМЕЩЕНИЯ

Из Excel с листами-маршрутами, например «Т10 на Т1»:
/excel перемещение

Создать пустую книгу для заполнения:
/excel шаблон перемещения с Т10

Создать перемещение прямо сообщением, без файла:
Т10 на Т1: SO3206 12, PJ10440 2
Т10 на Т7: SO3206 3

Обе строки можно отправить одним сообщением. После двоеточия — артикул и количество; разные товары разделяются запятой. Артикул должен содержать цифру. Лучше всегда указывать целое количество явно. Результат — Excel-документ, а не проведение перемещения в учётной системе.

8. НЕПРОДАННОЕ И ФИЛЬТР ПО НАЗВАНИЮ

/excel непроданное
/excel что не продалось
/excel неликвид

Собирает товары без розничных и оптовых продаж за период. Это не произвольный финансовый анализ неликвидности.

/excel оставь только pjur
/excel удали всё кроме презерватив

Фильтр оставляет строки, в названии которых есть указанный текст. Для артикула используй поиск. «Оставь только» формирует результат из подходящих данных; это не команда скрыть строки в открытом Excel. Исходник фильтр не перезаписывает.

9. ЛИСТЫ КНИГИ

/excel покажи листы
/excel создай лист Т9
/excel удали лист Т5
/excel переименуй лист Т5 в Т9
/excel скопируй лист Т5 в Т9

Имена Т5 и Т9 замени на свои. Перед изменениями удобно сначала запросить список листов. При изменении структуры бот сохраняет новую книгу и присылает её. Последний оставшийся лист удалить нельзя. Имя нового листа не должно совпадать с существующим. Для книги со встроенными картинками редактирование листов ограничено: пересохрани копию без картинок.

Если продолжаешь работу с полученной книгой, загрузи её обратно и укажи путь из ответа бота. Автоматическое переключение всех дальнейших действий на последний результат не гарантировано.

10. ПРАВКА ЗНАЧЕНИЙ

/excel поменяй артикул A123 на B456 в data/ostatki.xlsx
/excel измени цену на 199 у артикула PJ10050 в файле data/ostatki.xlsx на листе Т1

Это запрос к AI-планировщику правок. Укажи файл, лист, колонку для поиска, искомое значение и новое значение. Колонки должны реально существовать; заголовки для этого режима читаются из первой строки. Совпадающих строк может быть несколько.

Отличие от операций с листами: редактор ячеек сохраняет изменения в самом загруженном файле проекта, предварительно создавая резервную копию в backups/. Проверь отчёт о применённых и пропущенных правках. Свободная формулировка не гарантирует выполнение любого действия, например форматирования или создания диаграммы.

12. ЕСЛИ БОТ ПОНЯЛ НЕ ТО

• Отправляй одну операцию в одном сообщении.
• Для таблиц начинай с /excel.
• Используй точные примеры выше, затем меняй артикулы, точки и числа.
• Не добавляй к поиску товара длинное объяснение: оно может стать частью поисковой строки.
• Для расчётов указывай настоящий период отчёта и проверяй источники в ответе.
• Если получен общий текст AI вместо файла или отчёта об операции, это ещё не подтверждение изменения таблицы.
